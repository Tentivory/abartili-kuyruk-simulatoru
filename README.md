# Abartılı Kuyruk Simülatörü

## Dünyanın En Ciddi ve En Gereksiz Projesi

Bu proje, Türkiye'de (ve dünyada) yaşanan kuyruk çilesini bilimsel olarak simüle etmek amacıyla geliştirilmiştir. **Gerçekten çalışır.** Hiçbir zaman bitmez, sıra asla gelmez. Mükemmel bir zaman kaybıdır.

### Nasıl Çalışır?

1. Python 3 yüklü olsun.
2. `python kuyruk_simulatoru.py` komutunu çalıştır.
3. Sıranın uzamasını izle.
4. Gerçek hayattaki kuyruğuna dön.

### Özellikler

- Rastgele absürt sebepler üretir.
- Sıranız sürekli artar (hiç azalmaz).
- 15 adım sonra "bitti" der ama aslında bitmez.
- Ciddi bir yüz ifadesiyle yazılmıştır.

### Neden Var?

Çünkü birisi "boş yere repo aç" dedi. Anlamlı olması gerekmiyordu. Türkçe olsun yeter.

### Uyarı

Bu kodu çalıştırmak gerçek kuyrukları kısaltmaz. Hatta uzatabilir. Kullanıcı sorumluluğundadır.
